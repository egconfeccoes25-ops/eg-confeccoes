Conectar ao site

Para salvar peças novas, este painel precisa de uma chave de acesso do GitHub. Você faz isso uma vez só em cada aparelho.

  1. Abra github.com/settings/personal-access-tokens/new (entre na sua conta se pedir).
  2. Token name: Painel EG. Expiration: 1 year.
  3. Repository access: Only select repositories, e escolha este repositório.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Clique em Generate token, copie o código que começa com github_pat_ e cole abaixo.
Avançado

A chave fica guardada só neste aparelho e vale só para este repositório. Não compartilhe com ninguém.
